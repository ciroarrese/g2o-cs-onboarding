Pill-shaped call-to-action used for every conversion point on grow2on.com ("Pedí tu demo gratis", "Hablemos").

```jsx
<Button variant="primary">Pedí tu demo gratis</Button>
<Button variant="outline" iconRight="↓">Ver cómo funciona</Button>
<Button variant="primary" size="sm" href="/pages/hablemos">Hablemos</Button>
```

Variants: `primary`/`pink` (solid #e7007e + shadow-md, lifts 1px on hover), `outline` (1.5px pink border, fills pink on hover), `ghost`. Sizes: md 52px, sm 44px. Labels are sentence-case Spanish imperatives; arrows are plain Unicode characters, never icon SVGs.
